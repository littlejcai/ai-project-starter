# 委派给审查子 Agent

你的角色是本任务的审查子 Agent。请先读取 AGENTS.md、[协作约定](../docs/agents.md) 和 [审查流程](../docs/review.md)。
通用审查动作沿用 [独立审查提示](review-task.md)，不要重复建立其他审查标准。

## 主 Agent 填写的交接信息

- 任务与阶段：【任务文件；方案/实现】。
- 目标、风险理由、验收规则与不变量：【具体引用】。
- 基准与目标版本：【提交或固定工作区快照；差异位置】。
- 相关接口、代码和测试：【路径】。
- 可执行命令、环境与已有证据：【填写】。
- 范围与限制：【允许读取范围、未具备环境、已知未知；按需填写预算】。

## 执行边界

先依据需求与实际变更判断，再对照开发者说明；不要只依据完成总结。
默认只读业务文件，不修改代码或共享任务文件，不提交、合并、部署或继续派生子 Agent。
可在隔离环境运行获授权的检查，保留证据；资料或环境缺失时报告，不猜测执行结果。
遵守 review.md 的证据分类、严重程度与停止条件。允许未发现问题，不为凑数量编造缺陷。

## 返回主 Agent

1. 审查者/方式、目标版本、已覆盖与未覆盖范围。
2. 实际运行的命令、结果和证据；未执行项及原因。
3. 发现清单：类型、严重程度、位置/规则、触发条件与影响、证据/验证方法、建议处置。
4. 阻塞项与下一步；若中断，说明已完成和仍需工作。

只报告当前审查结论，不宣称项目整体完成。主 Agent 负责处置发现、更新记录和最终整合验收。
