# 新项目启动任务

读取 AGENTS.md 和 [初始化流程](../docs/workflow.md)；先核对已有产品、架构与状态，沿用有效结论。
项目需求：【用户、场景、目标、平台及已有约束】。
交付范围：【例如产品定义、最小技术方案、首条业务任务及可运行骨架】。
界面与品牌：【无用户界面 / 有界面但无现成规范 / 已有品牌或设计资产；如已有，给出位置、版本和适用范围】。

先核对界面与品牌输入：无用户界面时不创建体验文档；有实际界面交付时，在实现前按流程判断是引用已有规范还是按需创建单一 `docs/experience.md`。不要默认生成品牌、UX、UI 或设计系统目录，也不要预设具体审美和前端技术。
完成已授权范围，按需验证关键技术假设，并将真实检查接入 project.config.json。
阶段接入与推进按 [配置指南](../docs/verification-setup.md) 执行，不能将配置就绪当作验证通过。
结束时给出已完成产物、实际验证、未执行项与下一步；仅因关键歧义或授权边界需要用户决定时集中提出。
