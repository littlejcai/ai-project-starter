# 新项目启动任务

读取 AGENTS.md 和 [初始化流程](../docs/workflow.md)；先核对已有产品、架构与状态，沿用有效结论。
项目需求：【用户、场景、目标、平台及已有约束】。
交付范围：【例如产品定义、最小技术方案、首条业务任务及可运行骨架】。

完成已授权范围，按需验证关键技术假设，并将真实检查接入 project.config.json。
只详细展开当前和下一里程碑；目标阶段门禁就绪后 dry-run 并执行 promote_project.py，同步项目身份与状态。
结束时给出已完成产物、实际验证、未执行项与下一步；仅因关键歧义或授权边界需要用户决定时集中提出。
