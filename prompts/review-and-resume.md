# 接续任务（保留原文件名以兼容已有引用）

读取 AGENTS.md、docs/status.md、当前任务及相关规则。核对实际 Git 变更、接口、测试和运行环境。
从用户验收、边界、权限、一致性和证据充分性检查，不能只依据开发者摘要或绿灯判断正确。
明确发现的问题、影响和依据；重要缺陷补可复现测试。接续时按任务的下一步推进。
仅记录实际执行过的验证，缺少环境时写明未执行。结束时给出简短交接，避免复制全部历史。

本提示用于恢复工作与核对既有证据，不等于已完成独立审查。
需要正式方案/实现审查时，使用 [review-task.md](review-task.md) 并按 docs/review.md 记录。
恢复时核对任务风险、假设是否失效、未解决审查项及其处置；没有新事实不要重做完整分析。
