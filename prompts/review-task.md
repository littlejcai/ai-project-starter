# 独立审查任务

请读取 AGENTS.md、docs/review.md、目标任务【docs/tasks/FEAT-xxx.md】及相关需求/约定。
阶段：【方案/实现】；目标版本或范围：【填写】。

先依据需求、规则和实际方案/差异独立判断，再对照开发者结论。按风险寻找边界、权限、重复/乱序/并发、部分失败与恢复方面的反例，同时检查测试预期与有效性。
默认只审查，不改业务代码；需要时在隔离环境运行现有检查或做最小复现，并保留证据。
每项发现按 docs/review.md 记录类型、严重程度、位置、条件、影响、证据/验证方法及建议处置。
禁止为了凑数编造缺陷；允许未发现问题，明确未覆盖范围。不要把未验证风险当作已确认缺陷，不把风格偏好当作阻塞项。
记录实际审查者/方式和独立程度。完成后给出阻塞项、非阻塞项及下一步，满足停止条件即结束。
