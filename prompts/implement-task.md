# 实现一个任务

请读取 AGENTS.md 和任务文件【docs/tasks/FEAT-xxx.md】，按索引只补充相关上下文。
检查当前代码和已有变更，保留用户工作。补齐验收场景、当前功能的接口与数据约定。
对关键规则执行测试失败→实现通过→重构；及时完成真实集成与界面检查。
如修正测试预期，记录业务依据；不能为了绿灯弱化断言。
执行相关检查并更新任务证据、未执行项、当前状态；在已授权范围内推进，不扩大产品范围。

先按 docs/principles.md 判断风险，引用已确认目标/约束与假设，写清当前不变量和必要恢复路径。
按风险选择方案或实现审查，可使用 [独立审查提示](review-task.md)；与实现过程明确区分。
审查结论按 docs/review.md 记录证据与处置。完成停止条件即结束，只对修复及影响范围复查。
