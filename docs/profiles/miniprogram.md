# 微信小程序项目路径

选择原生或跨端框架前，先验证关键平台能力；记录开发者工具版本、基础库版本、AppID 配置方式和后端测试环境。
具体自动化能力、宿主机要求与工具版本，在实际项目接入时以官方文档及本机工具为准。

## 接入顺序

1. 将独立业务规则从页面中分离，优先做快速规则测试。
2. 接入真实测试接口和隔离数据，验证权限与状态变化。
3. 在微信开发者工具中编译、操作核心流程；具备条件时接入可重复的自动化脚本。
4. 在实际支持的真机上验证项目用到的登录授权、分享、定位、上传、键盘、前后台切换及网络失败。

## 验收记录

记录设备/系统、微信版本、基础库版本、构建或提交、账号类型、操作与结果。真机不具备条件时写明未执行和所需条件。
浏览器测试不能直接替代原生小程序运行环境；开发者工具通过也不能替代必要真机验证。
CI 若不能启动开发者工具，将相应检查明确记录为人工步骤；按 verification-setup.md 有理由地标明自动 gate 的适用性。
