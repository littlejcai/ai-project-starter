# 网页项目路径

选择前端/服务端后，建立安装、启动、构建、快速测试和端到端命令，接入 project.config.json。

## 第一条完整链路

页面输入 → 真实测试接口 → 隔离数据库 → 返回状态 → 刷新后结果保持。
早期可用模拟接口做交互，但在任务记录中标明，尽早替换到实际链路。

## 自动与人工验证

端到端工具可选择 Playwright 等；根据选型核对官方安装和浏览器依赖。
测试命令必须负责启动/等待服务并结束自己创建的服务，不能假定某个本地服务永远运行。
使用稳定的可见标签与可访问角色定位，独立测试数据，等待具体状态而非固定睡眠。
验证正常、空、加载、失败、无权限、重复提交；按支持范围检查手机/桌面布局。
截图用于排版检查，不能单独证明交互和数据正确。

自动报告通过后仍需实际体验关键流程，发布前在目标环境执行冒烟检查。
